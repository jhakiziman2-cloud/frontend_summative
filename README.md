i# Campus Life Planner

## Project Overview

Campus Life Planner is a simple web application designed to help students organize their academic tasks and manage their study time. It allows students to create tasks, set deadlines, track their progress, and plan their daily activities in one place.

## Main Features

The application allows students to add, edit, and delete tasks. Students can search for tasks using regular expressions and sort tasks to find information more easily. The dashboard displays statistics about tasks and study time, helping students understand their progress. Users can also set time limits, change time units, and view their progress through visual information.

## How to Run the Project

To run the application, download the project folder and open it on your computer. Open the index.html file in a web browser to access the Campus Life Planner. You can then create tasks, manage deadlines, and explore the available features.

## Data Storage

The application uses browser storage to save tasks. This allows tasks to remain available when the user refreshes the page or opens the application again in the same browser. The project also includes a seed.json file containing sample task data that can help with testing and demonstration. Users can import and export task information using JSON files.

## Testing

The application can be tested by creating, editing, and deleting tasks. Users can also test regular expression search, sorting, dashboard statistics, time limits, and settings. Refreshing the page helps confirm that tasks are saved correctly. Importing and exporting data can also be tested to ensure that task information can be transferred successfully.

## Accessibility

Campus Life Planner aims to provide a clear and accessible experience for students. It uses readable text, labelled form fields, keyboard navigation, and feedback for important actions. The layout is designed to work on different screen sizes so that students can use the application on computers, tablets, and mobile devices.

## Project Purpose

The purpose of this project is to help students manage their academic responsibilities in an organized and practical way. It also demonstrates how HTML, CSS, and JavaScript can be used to build an interactive web application with form validation, data management, search, statistics, and browser storage.
